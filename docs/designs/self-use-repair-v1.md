## Problem Statement

创始人做了一款 PyQt5 透明悬浮窗实时翻译 App（截屏 OCR + 系统音频 → 翻译 → 悬浮窗显示），自评「比较简陋」，诉求是整体查缺补漏、实时落地使用；同时希望做成产品给别人用。经 startup 诊断确认当前阶段：先把软件修到自己每周真用（dogfooding），成为第一个重度用户，再谈产品化。

## Demand Evidence

Q1 答案：只有自己在用。无任何外部需求证据。这是产品化的第一个空白。
创始人本人的痛点真实存在：看生肉视频「忍着或放弃不看」。

## Status Quo

Q2 答案：创始人现状是「忍着或放弃不看」——痛感低于「下载一个免费工具」的摩擦（自己做的工具也没频繁用）。市场扫描（2026-09）：pot-desktop、TTime、eSearch、Umi-OCR（47k stars）、Lingolay 等免费桌面工具成群；浏览器插件（沉浸式翻译、Language Reactor）覆盖流媒体场景；剪映/CapCut 一键双语字幕吃掉录播场景；会议场景被 DeepL Voice/Zoom/Teams 原生字幕覆盖（Slator 2026 测评 DeepL Voice 96.4 分 vs Google Meet 87）。赛道无空白。

## Target User & Narrowest Wedge

Q3 答案：目标人群是「看英文教程的人」。诊断意见：该人群被 YouTube 官方双语字幕 + 浏览器插件覆盖最好，且悬浮窗单行译文是追剧形态，与学习理解场景错配。形态真正匹配的是「本地生肉视频」人群（浏览器插件用不上的场景）。
最窄楔子：让自己每周真用它看 2 部生肉视频——这是当前唯一的真实用户。

## Constraints

- 国内网络：Google 翻译（deep-translator 的 MyMemory/GoogleTranslator）与 Google STT 不可直连，必须换 LLM API（cnsai 中转站优先 / DeepSeek 兜底）或本地模型
- Windows 11 桌面 + PyQt5 技术栈
- PyInstaller 打包已就绪（3 个 spec 文件）
- 本机 gstack 工具链 bun 未安装（环境备注，与产品无关）

## Premises

1. P1 赛道无空白，追平免费竞品不构成差异化，分发才是最大瓶颈 — 同意
2. P2 教程人群错配，悬浮窗形态匹配的是本地生肉视频人群 — 同意
3. P3 国内网络下 Google 免费翻译/STT 不可用，必须换 LLM API 或本地模型 — 同意

## Approaches Considered

### Approach A: 自用修复版（最小可行，已选）

把项目修到创始人每周真用：去重器补模糊匹配、翻译队列限长+最新优先、LLM 后端接入（国内可用）、README、打包验证、修音频竞态。不改形态、不做分发。Effort S-M / Risk Low。

### Approach B: 生肉场景重构（理想架构，搁置）

按 2026 品类标准重做：LLM 上下文窗口翻译、.srt 导出、本地/中转双后端、GitHub 开源分发。Effort L-XL / Risk Med-High。搁置原因：工作量与「分发瓶颈未解」不成比例，且无生肉人群需求证据。

### Approach C: 两周验证路线（横向，搁置）

打包现有 exe → 找 3 个真实用户当面观察 → dogfooding 两周 → 用证据决定路线。搁置原因：用户当前诉求是补全项目本身；其「找 3 个真实用户观察」动作并入 The Assignment。

## Recommended Approach

**A：自用修复版**。理由：直接满足「实时落地使用」诉求；是 B/C 的不可跳过前置（没有能天天用的软件，拿什么去验证、去重构）；沉没成本仅 1-2 个会话，做完再决定走 C 还是 B。

范围收缩标记：本路线刻意不追品类标准（LLM 上下文窗口、本地离线模型、TTS 配音、.srt 导出）。升级触发条件：出现第 1 个真实外部用户追着要新版。

## Open Questions

1. 创始人自己为什么「忍着不用」现成免费工具：不知道存在 / 试过难用 / 看片频率低不值得？—— 下次 office-hours 的第一问
2. 教程人群 vs 生肉人群的最终取舍（留给 C 路线的用户观察验证）
3. 翻译质量：LLM 单句翻译 vs 上下文窗口翻译（本版本按单句修复，上下文窗口属于 B 路线）

## Success Criteria

- 自己每周用它看 ≥2 部生肉视频，且不觉得碍事
- 从点开始到看到译文 <3 秒；翻译成功率 >95%（国内网络环境）
- 有 README：一个完全没碰过本项目的人按 README 能装上并跑起来
- 产品化门槛：出现第 1 个「追着你要新版」的外部用户 —— 达到后升级到 B 路线

## Distribution Plan

自用阶段：PyInstaller 一键打包 exe（spec 已存在），本地使用。GitHub Releases + CI 延后到有外部用户需求时。

## Dependencies

- LLM API key：从 cnsai 中转站 proxy 配置（本机 127.0.0.1:8642）或 DeepSeek 官方获取，密钥不落库、不进 README
- 修复清单（按优先级）：① 去重器模糊匹配（Levenshtein 已实现未接线）② 翻译队列限长+最新优先 ③ LLM 翻译后端接入 ④ README ⑤ 音频线程竞态 ⑥ OCR asyncio.run 每帧重建事件循环 ⑦ 历史目录改绝对路径 ⑧ OCR 语言暴露到设置界面 ⑨ 翻译失败用户提示

## The Assignment

用修复后的版本，本周内看 2 部生肉视频（或英文视频）。每次看完记 3 行：什么场景好用、什么场景想关掉它、什么功能让你抓狂。下周带着这份记录回来——这是产品化之前最重要的一份数据。
